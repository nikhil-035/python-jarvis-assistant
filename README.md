# 🤖 Python Jarvis Assistant

A Python-based AI voice assistant inspired by Jarvis. This project can recognize voice commands, respond using text-to-speech, open websites, provide weather updates, tell the current time, and integrate with the Google Gemini API for AI-powered conversations.

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Text-to-Speech
- 🌐 Open Websites
- 🕒 Tell Current Time
- 🌦️ Weather Information
- 🤖 AI Chat using Google Gemini
- 💻 Command-Line Interface

## 🛠️ Technologies Used

- Python 3
- SpeechRecognition
- pyttsx3
- Requests
- Google Gemini API
- WeatherAPI

## 📦 Required Libraries

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install requests
pip install google-genai
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/python-jarvis-assistant.git
```

2. Install the required libraries.

3. Replace the placeholder API keys with your own API keys.

4. Run:

```bash
python jarvis.py
```

## ⚠️ Security

Do **not** upload your real API keys.

Replace them with placeholders such as:

```python
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
WEATHER_API_KEY = "YOUR_WEATHER_API_KEY"
```

or use a `.env` file to store them securely.
